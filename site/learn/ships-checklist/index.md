# Ship’s Checklist

Add “Check the weather” to a departure checklist, then mark it complete. Each guide builds a different way to do that job. Start with the web app to see your first change in the browser.

| Build | What you’ll do |
| --- | --- |
| [Web checklist](web.md) | Turn a Razor page into a working form and share the checklist across requests with a Caravel service provider. |
| [Command-line checklist](cli.md) | Keep tasks in a local file and print a receipt with a Caravel event listener. |
| [Checklist API](api.md) | Send tasks as JSON and retrieve them after a restart using Clarion and SQLite. |

Each project runs on its own. To compare your files with the finished projects, [download the source](/ships-checklist.zip).
