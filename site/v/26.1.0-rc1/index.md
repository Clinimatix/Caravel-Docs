# Clinimatix Caravel documentation

New here? Start with the [repository README](/v/26.1.0-rc1/overview) and its quick start.

## The basics

- [Getting started](/v/26.1.0-rc1/getting-started): how a Caravel app starts up, and what it sets up for you
- [Configuration](/v/26.1.0-rc1/configuration): settings files, `.env` and environment variables
- [Development sessions](/v/26.1.0-rc1/development): watch your web app and run a worker with one command
- [Hosting](/v/26.1.0-rc1/hosting): run web apps and workers as services, containers or IIS sites

## Data

- [Clarion](/v/26.1.0-rc1/clarion): query and save models, soft deletes, factories and seeders
- [Bosun data commands](/v/26.1.0-rc1/bosun-data): generate models and run migrations and seeders
- [Database providers](/v/26.1.0-rc1/database-providers): which databases you can use today

## Authentication

- [Local accounts](/v/26.1.0-rc1/authentication): ASP.NET Core Identity with secure defaults
- [Sign in with an identity provider](/v/26.1.0-rc1/oidc-authentication): OpenID Connect for browser sign-in
- [Service authentication](/v/26.1.0-rc1/service-authentication): protect APIs with bearer access tokens
- [Windows authentication](/v/26.1.0-rc1/windows-authentication): intranet sign-in with organizational accounts

## Application services

- [Events](/v/26.1.0-rc1/events): notify other parts of your app
- [Queues](/v/26.1.0-rc1/queues): durable background jobs that survive restarts
- [Mail](/v/26.1.0-rc1/mail): transactional email, templates, attachments and queued sending
- [Notifications](/v/26.1.0-rc1/notifications): replaceable mail and SMS delivery channels
- [Scheduling](/v/26.1.0-rc1/scheduling): enqueue recurring work at fixed intervals
- [Bosun service generators](/v/26.1.0-rc1/bosun-services): generate jobs, events and listeners
- [Local storage](/v/26.1.0-rc1/storage): stream files into named storage disks
- [Caching](/v/26.1.0-rc1/caching): use .NET's memory and SQL Server caches
- [Observability](/v/26.1.0-rc1/observability): queue metrics, tracing and health checks
