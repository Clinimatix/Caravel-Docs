New here? Start with the [repository README](/v/26.1.3-rc3/overview) and its quick start.

- [Getting started](/v/26.1.3-rc3/getting-started): how a Caravel app starts up, and what it sets up for you

## Authentication

- [Local accounts](/v/26.1.3-rc3/authentication): ASP.NET Core Identity with secure defaults
- [Sign in with an identity provider](/v/26.1.3-rc3/oidc-authentication): OpenID Connect for browser sign-in
- [Service authentication](/v/26.1.3-rc3/service-authentication): protect APIs with bearer access tokens
- [Windows authentication](/v/26.1.3-rc3/windows-authentication): intranet sign-in with organizational accounts

## Application services

- [Fathom application tools](/v/26.1.3-rc3/fathom-tools): explicit in-process registration, authorization and fake handlers

- [Events](/v/26.1.3-rc3/events): notify other parts of your app
- [Queues](/v/26.1.3-rc3/queues): durable background jobs that survive restarts
- [Mail](/v/26.1.3-rc3/mail): transactional email, templates, attachments and queued sending
- [Notifications](/v/26.1.3-rc3/notifications): replaceable mail and SMS delivery channels
- [Scheduling](/v/26.1.3-rc3/scheduling): enqueue recurring work at fixed intervals
- [Bosun service generators](/v/26.1.3-rc3/bosun-services): generate jobs, events and listeners
- [Local storage](/v/26.1.3-rc3/storage): stream files into named storage disks
- [Azure Blob storage](/v/26.1.3-rc3/azure-storage): optional Azure SDK adapter, conditional transfers and authorized downloads
- [Caching](/v/26.1.3-rc3/caching): use .NET's memory and SQL Server caches
- [Observability](/v/26.1.3-rc3/observability): queue metrics, tracing and health checks
