# Clinimatix Caravel documentation

New here? Start with the [repository README](/v/dev/overview) and its quick start.

## The basics

- [Getting started](/v/dev/getting-started): how a Caravel app starts up, and what it sets up for you
- [Configuration](/v/dev/configuration): settings files, `.env` and environment variables
- [Development sessions](/v/dev/development): watch your web app and run a worker with one command
- [Hosting](/v/dev/hosting): run web apps and workers as services, containers or IIS sites

## Data

- [Clarion](/v/dev/clarion): query and save models, soft deletes, factories and seeders
- [Bosun data commands](/v/dev/bosun-data): generate models and run migrations and seeders
- [Database providers](/v/dev/database-providers): which databases you can use today

## Authentication

- [Local accounts](/v/dev/authentication): ASP.NET Core Identity with secure defaults
- [Sign in with an identity provider](/v/dev/oidc-authentication): OpenID Connect for browser sign-in
- [Service authentication](/v/dev/service-authentication): protect APIs with bearer access tokens
- [Windows authentication](/v/dev/windows-authentication): intranet sign-in with organizational accounts

## Application services

- [Events](/v/dev/events): notify other parts of your app
- [Queues](/v/dev/queues): durable background jobs that survive restarts
- [Mail](/v/dev/mail): transactional email, templates, attachments and queued sending
- [Notifications](/v/dev/notifications): replaceable mail and SMS delivery channels
- [Scheduling](/v/dev/scheduling): enqueue recurring work at fixed intervals
- [Bosun service generators](/v/dev/bosun-services): generate jobs, events and listeners
- [Local storage](/v/dev/storage): stream files into named storage disks
- [Caching](/v/dev/caching): use .NET's memory and SQL Server caches
- [Observability](/v/dev/observability): queue metrics, tracing and health checks
